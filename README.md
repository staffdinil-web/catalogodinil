# Catálogo Dinil para GitHub Pages

Este projeto recria o layout do catálogo atual em arquivos simples e editáveis.

## O que editar

### Textos e páginas
Edite `catalogo.json` diretamente pelo GitHub. Para alterar um texto, clique no arquivo, depois no ícone de lápis, faça a alteração e clique em **Commit changes**.

### Imagens
Envie para a pasta `catalogo` estas imagens:

- `catalogo-moura-1.png`
- `catalogo-moura-2.png`

Se usar outro nome, atualize o campo `imagem` no arquivo `catalogo.json`.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie todos os arquivos e a pasta `catalogo`.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione `main` e `/(root)`.
6. Clique em **Save**.

O endereço ficará parecido com:

`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## Observação

Não edite os antigos arquivos `index-*.js` minificados. Eles são resultado de compilação. Nesta versão, o conteúdo editável fica centralizado em `catalogo.json`, e o visual fica em `style.css`.
